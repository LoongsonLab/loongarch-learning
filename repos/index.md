# 龙架构相关仓库

本页汇总与 **LoongArch / 龙架构** 开发、教学与平台相关的常用开源托管入口，便于按主题跳转查阅。

- **[龙芯实验室开源仓库](/repos/loongsonlab)**：龙芯实验室参与的模拟器、开放芯片平台、教学 OS、汇编工具与架构文档等，按 **Open-ChipHub** 与 **LoongsonLab** 两个 GitHub 组织分别列出。
- **[龙芯开源社区](/repos/loongson-community)**：龙芯及社区在 Gitee/GitHub 上的官方与社区帐号、鸿蒙龙架构主线等项目入口。
