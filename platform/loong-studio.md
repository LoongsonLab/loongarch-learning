# Loong-Studio汇编运行模拟器使用说明

Loong-Studio 汇编运行模拟器，提供面向 LoongArch/Loong64 开发与调试的桌面 IDE 体验，集成汇编、运行与调试工作流。

在该平台上，用户可以自由编辑面向 LoongArch 指令的汇编文件，并调用原生 LoongArch 编译工具链，进行编译。同时，后端可以直接调用 LoongArch 模拟器，运行汇编文件，并提供单步运行、运行结果 Diff 等丰富的调试功能。

平台支持 x86 架构下 Windows ，Linux 系统桌面环境下使用。
