# 龙架构与操作系统底层的交互

此文档结合代码例子详细了介绍龙架构底层如何与操作系统内核配合。读完这个文档，可以很快的给一个操作系统内核增加LoongArch的支持。
[点击阅读](https://os-kernel-with-loong64-doc.readthedocs.io/en/latest/)


内容整体如下： 

-  本文档是对LoongArch架构与底层操作系统的紧密相关文档，类似于对linux内核的目录arch/loongarch下做个说明。
-  特权态指令的一些说明，结合模拟器做出伪代码的说明。 
-  DMW的使用与说明，以及使用的场合说明。 
-  LA的内存管理系统，包括TLB相关寄存器的初始化，LA的TLB refill指令，tlb的使用等等（这部分也是难点） 
-  LA的中断系统，如何更加采用一个合理的中断安排等 
-  LoongArch的新世界与旧世界，我们为什么要采用新世界，如何使用新世界等等 
-  LoongArch ABI2.0的介绍与使用，伪代码实例等等
-  如何调试一个内核，以一个内核为例，如何使用上游的qemu以及gdb支持调试操作系统等等。
